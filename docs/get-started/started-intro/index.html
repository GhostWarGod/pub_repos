A new era of blockchain competitive gaming - play to earn made simple

1. 🐍 What is Crypto Snake​

( 1 ) Crypto Snake Game​

Core Gameplay​

  • Classic snake gameplay
  • Various item experiences
  • Multiplayer online PvP
  • Blockchain elements

Game Features​

Players control a snake, eating food to make it grow longer while avoiding collisions with other snakes or walls. The goal is to make your snake as long as possible, eliminate other players, and become the strongest snake on the map.

2. 💎 What are Diamonds​

4. 🎯 How to Play​

  • Direction Control: Players control the snake's movement direction through virtual joystick by swiping the screen
  • Acceleration: Rapidly increase speed
  • Eat Food: Food randomly spawns on the map, snake grows when touching food
  • Use Items: Using items produces corresponding game experiences
  • Game Over: After game ends, players can choose to restart or return to game lobby

( 1 ) Collision Rules​

  • Hit wall = death, game over
  • Hit another snake's body = death
  • Head-to-head collision: shorter snake dies
  • Head-to-head collision with equal length: the snake that entered later dies

( 2 ) Game Exit​

  • Last player in room exits: entry fee automatically refunded
  • Other exit scenarios: entry fee not refunded

( 3 ) Game Rewards​

  • Winner receives loser's entry fee reward
  • Loser exits game and receives system diamond rewards, experience points, and random items

5. 💰 How to Earn Money​

( 1 ) 7 Ways to Earn​

  • Free mode: 10 daily chances to earn diamonds and random items
  • Endless mode and club mode: earn diamonds, tokens, random chests, and random item rewards through PvP, 100% diamond guarantee
  • Upgrade snake pets with items dropped from gameplay to get epic snake NFTs, then sell on platform marketplace
  • Open treasure chests to get legendary snake NFTs, BTC, USDT and other prizes from platform prize pool
  • Regular players get 3% game commission from friend referrals
  • Club players get 5%~10% game commission from friend referrals
  • Token airdrops when new projects launch
