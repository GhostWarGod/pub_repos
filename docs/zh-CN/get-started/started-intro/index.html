区块链竞技游戏新时代，边玩边赚钱更简单

1. 🐍 什么是加密蛇​

( 1 ) 加密蛇游戏​

核心玩法​

  • 经典贪吃蛇玩法
  • 多种道具体验
  • 多人同时在线PK
  • 区块链元素

游戏特色​

玩家控制一条蛇，通过吃食物让蛇变长，并尽量避免碰到其他蛇或墙壁。游戏的目标是尽量让自己的蛇变长，击杀其他玩家，成为地图上最强大的蛇。

2. 💎 钻石是什么​

  • 游戏内资产，通过玩游戏产生
  • 可以在平台交易
  • 可以兑换为平台权益代币CNB
  • 游戏内产生总量：126,000,000，占CNB总供应量的63%。
  • 目标: 1 钻石 = 1 BNB

4. 🎯如何玩游戏​

  • 控制方向: 玩家通过滑动屏幕虚拟控制摇杆进行控制蛇的前进方向
  • 加速： 迅速增加速度
  • 吃食物：地图上会随机生成食物，蛇碰到食物会变长。
  • 使用道具：使用道具会产生相应的游戏体验
  • 游戏结束：游戏结束后，玩家可以选择重新开始游戏或者返回游戏大厅

( 1 ) 碰撞规则​

  • 撞墙死亡,游戏结束
  • 撞到其他蛇的身体会死亡
  • 两蛇头部相撞，身体短的蛇死亡
  • 两蛇头部相撞，身体长度相等，后进入的蛇死亡

( 2 ) 游戏退出​

  • 房间内最后一个玩家退出，退出游戏，门票自动退回
  • 其他情况退出游戏，门票不予退回

( 3 ) 游戏奖励​

  • 胜方获得失败方的门票奖励
  • 失败方退出游戏，获得系统钻石奖励、经验值和随机道具奖

5. 💰 如何赚钱​

( 1 ) 7种赚钱途径​

  • 自由场，每天10次机会赚钻石和随机道具
  • 无尽模式和俱乐部模式，通过PK获得钻石、代币、随机宝箱和随机道具奖励，钻石100%获得。
  • 通过玩游戏掉落的道具，可以升级蛇宝获得史诗级的蛇NFT，然后在平台的市场上出售。
  • 开宝箱可以从平台抽奖池获得传奇蛇NFT、BTC、USDT等奖品。
  • 普通玩家邀请好友获得3%的游戏佣金。
  • 俱乐部玩家邀请好友获得5%~10%的游戏佣金。
  • 新项目上线时会空投代币奖励。
