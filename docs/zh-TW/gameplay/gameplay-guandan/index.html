Crypto Guandan

這是一款中國非常流行的撲克牌遊戲——掼蛋的玩法。它融合了"跑得快"和"升級"的特點，講究團隊配合與策略。

遊戲基礎資訊​

  • 玩家人數：4人，兩兩組隊，對坐的玩家為隊友
  • 使用牌數：兩副完整的撲克牌（共108張），包含大小王
  • 核心目標：隊友合作，盡可能爭先出完手牌。每局以"升級"方式決定勝負

牌型與大小​

由大到小排序：

牌型描述大小比較
四大天王 ( 天王炸 )兩張大王+兩張小王 最大牌型 可打任何牌無敵
炸彈四張牌或以上點數相同（如四個7）八張炸彈可以打七張，以此類推張數多，同張數，點數大者大
同花順五張或以上花色相同，點數連續的牌（如黑桃45678）比長度,越長越大，同長度時，比最大牌的點數
普通炸彈四張點數相同的牌（如四個K），最小的炸彈點數高者大
其他牌型單張，對子，三連隊，三張，三帶二，順子等需要與上家出牌的類型，張數完全相同才能比較，按點數比大小

除炸彈類牌型外，其他牌型必須"壓"同類型、同張數的牌。

逢人配：每局當前級數的紅桃花色的牌（如打2，則紅桃2是"逢人配"）是萬能牌，可替代除大小王外的任何牌組成牌型（例如，與另外兩張2組成炸彈，或與567組成同花順）。

遊戲流程與規則​

1. 開局與發牌​

隨機一人先發牌，每人27張。第一局由翻出明牌者先出。

2. 進貢與還貢​

  • 上局失敗方（下游）需向獲勝方（上游）進貢自己手中最大的一張牌（紅桃級牌除外）
  • 上游需返還一張無用的牌
  • 若下游握有雙大王，則可免貢，由上游先出牌

3. 出牌與跟牌​

首家出任意符合規則的牌型，下家必須出更大的同類型牌或使用炸彈（包括同花順）來壓制，也可以選擇不出（Pass）。

4. 報牌與頭遊​

當玩家手牌剩餘10張、6張、3張、1張時，必須主動報數，提醒對手。

5. 確定勝負​

  • 一隊兩名玩家分獲第一名（頭遊）和第二名（二遊），則對方兩人分別為三遊、下游（末遊），獲勝方升3級
  • 若一隊兩人獲頭遊和三遊，則升2級
  • 若一隊兩人獲頭遊和末遊，則升1級
  • 先打過"A"並獲勝的一隊，即贏得整場比賽

打A規則：打A時，必須本隊兩人都是頭遊才能最終獲勝，否則需繼續打A。

核心策略與口訣​

1. 隊友配合​

記住"上家頂，下家讓"。作為上家，要盡力用大牌頂住對手，為隊友創造機會；作為下家，在隊友是上游時，要盡量放小牌讓隊友接風。

2. 炸彈使用​

炸彈是奪得出牌權的利器，不要輕易浪費在無意義的壓制上，最好用來幫助隊友獲得頭遊或阻止對手上游。

3. 出牌權控制​

爭取出牌權，可以打出隊友擅長接的牌型。

4. 記牌與算牌​

記住大牌（大小王、主牌級牌）和已出的炸彈數量，推算剩餘牌型分佈，是高水平玩家的標誌。

5. 接風規則​

當一名玩家出完最後手牌，如果下一家是其隊友，則該隊友獲得下一輪的首出權（接風），這是非常重要的翻盤或鞏固優勢的機會。

6. 房間模式​

Crypto Guandan 通常提供多種不同的房間模式，主要包括：

自由場： 新手玩家的學習模式，練習遊戲的基本操作。 無盡模式： 系統房間，玩家需要支付門票進入遊戲，在公平規則的情況下互相競爭,玩家通過消除元素對其他玩家進行攻擊，最終獲勝者，系統會根據玩家表現給予獎勵 俱樂部模式： 俱樂部可以自定義房間，使用自己的數字資產作為門票。 自定義房間： 玩家自定義規則，需要支付門票進入遊戲。

Crypto Arena平台遊戲特點​

  • 快速上手：進入遊戲只需3秒，每局對決90秒
  • 技巧競技：強調依靠速度和技巧決定勝負
  • 雙重獎勵：獲勝方獲得代幣獎勵，失敗方獲得平台鑽石
