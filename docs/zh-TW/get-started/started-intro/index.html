區塊鏈競技遊戲新時代，邊玩邊賺錢更簡單

1. 🐍 什麼是加密蛇​

( 1 ) 加密蛇遊戲​

核心玩法​

  • 經典貪吃蛇玩法
  • 多種道具體驗
  • 多人同時在線PK
  • 區塊鏈元素

遊戲特色​

玩家控制一條蛇，通過吃食物讓蛇變長，並盡量避免碰到其他蛇或牆壁。遊戲的目標是盡量讓自己的蛇變長，擊殺其他玩家，成為地圖上最強大的蛇。

2. 💎 鑽石是什麼​

  • 遊戲內資產，通過玩遊戲產生
  • 可以在平台交易
  • 可以兌換為平台權益代幣CNB
  • 遊戲內產生總量：126,000,000，佔CNB總供應量的63%。
  • 目標: 1 鑽石 = 1 BNB

4. 🎯 如何玩遊戲​

  • 控制方向: 玩家通過滑動屏幕虛擬控制搖桿進行控制蛇的前進方向
  • 加速： 迅速增加速度
  • 吃食物：地圖上會隨機生成食物，蛇碰到食物會變長。
  • 使用道具：使用道具會產生相應的遊戲體驗
  • 遊戲結束：遊戲結束後，玩家可以選擇重新開始遊戲或者返回遊戲大廳

( 1 ) 碰撞規則​

  • 撞牆死亡,遊戲結束
  • 撞到其他蛇的身體會死亡
  • 兩蛇頭部相撞，身體短的蛇死亡
  • 兩蛇頭部相撞，身體長度相等，後進入的蛇死亡

( 2 ) 遊戲退出​

  • 房間內最後一個玩家退出，退出遊戲，門票自動退回
  • 其他情況退出遊戲，門票不予退回

( 3 ) 遊戲獎勵​

  • 勝方獲得失敗方的門票獎勵
  • 失敗方退出遊戲，獲得系統鑽石獎勵、經驗值和隨機道具獎

5. 💰 如何賺錢​

( 1 ) 7種賺錢途徑​

  • 自由場，每天10次機會賺鑽石和隨機道具
  • 無盡模式和俱樂部模式，通過PK獲得鑽石、代幣、隨機寶箱和隨機道具獎勵，鑽石100%獲得。
  • 通過玩遊戲掉落的道具，可以升級蛇寶獲得史詩級的蛇NFT，然後在平台的市場上出售。
  • 開寶箱可以從平台抽獎池獲得傳奇蛇NFT、BTC、USDT等獎品。
  • 普通玩家邀請好友獲得3%的遊戲佣金。
  • 俱樂部玩家邀請好友獲得5%~10%的遊戲佣金。
  • 新項目上線時會空投代幣獎勵。
